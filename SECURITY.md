# Security Policy

## Supported versions

Only the latest release receives security fixes. The in-app updater offers it
automatically; please update before reporting.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
**Security → Report a vulnerability** on this repository
(<https://github.com/Xslx98/LRReader/security/advisories/new>).
Do not open a public issue for a security problem.

Include what you can of:

- the app version (Settings → About) and Android version;
- the steps to reproduce, or a proof of concept;
- the impact you expect (for example, which data an attacker could read or change).

You can expect an acknowledgement within a week. Fixed issues are credited in
the release notes unless you ask otherwise.

## Scope

In scope: this app and its handling of server credentials (API keys),
cleartext/LAN connections, the app lock, downloaded files and the in-app updater.

Out of scope: vulnerabilities in the LANraragi server itself; please report
those to the [LANraragi project](https://github.com/Difegue/LANraragi).
