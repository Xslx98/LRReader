LR Reader 是一个功能丰富的 LANraragi 安卓客户端，基于 EhViewer 阅读框架开发。

功能特性：
• 全功能搜索 — 关键词、分类筛选、排序、随机推荐，按服务器保存搜索历史
• 高性能阅读 — GL 渲染 + 按需解码 + 智能预加载
• 合订本 — 整本无缝阅读，专属详情页与标签，一键整本下载
• 离线下载 — 后台下载整本档案，断点续传，边下边读
• 进度同步 — 阅读进度与服务器双向同步，按服务器分开保存
• 备份与恢复 — 服务器（不含 API Key）、历史、收藏、进度与设置导出为文件
• 标签翻译 — 中文环境下自动翻译标签（EhTagDatabase）
• 档案评分 — 基于标签的 emoji 星级评分
• 分类管理 — 浏览、创建、编辑 LANraragi 分类
• 安全 — API Key 用 Android 密钥库加密，图案应用锁，明文 HTTP 服务器标注「未加密」
• 多服务器 — 支持配置和切换多个 LANraragi 实例
• 上传管理 — 从设备上传档案 / 通过 URL 下载到服务器
• 远程删除 — 带倒计时确认的服务器档案删除
• 注重隐私 — 无统计 SDK，崩溃报告只存本机，由你决定是否分享
• 10 种语言 — 中文简繁/粤语、日/韩/英/法/德/西/泰
• 深色模式 — 跟随系统主题，支持纯黑模式
